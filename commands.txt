VoiceAssistant (Джарвис) — справочник команд
=============================================

По коду веток main / experimental: assistant.py, commands.py, dialogue_repair.py,
triggers.py, context_manager.py, intents.json и skills/.

Сравнение в основном подстрочное (фраза внутри реплики), если не сказано иное.
Буква «ё» приводится к «е».


Каналы
------
1. Голос: имя → сессия внимания → маршрутизатор.
2. Telegram: сразу в маршрутизатор (имя не нужно). «стоп» / «замолчи» / «спать»
   с телефона гасят Piper, не только поток Groq.
3. CLI: `python cli.py` (озвучка очередью). Тихий: `--mute`.


1. Имена активации
------------------
«джарвис», «умник», «гаврила», «гаврюша».

Vosk нормализует типичные опечатки («дарвис», «сервис», «гаврило», «гав рюша»,
«говорю же» и др.). Первое слово сравнивается нечётко со списком имён.

Только имя → «Да?» / «Слушаю.» / «Здесь.» / «На связи.»
Сессия зелёная, Audacious приглушается до DUCKING_VOLUME (по умолчанию 8%).
При DUCKING_MODE=pause — пауза плеера.

Имя + команда в одной фразе — команда сразу (имя вырезается).


2. Сессия, паузы, ремонт диалога
--------------------------------
ATTENTION_TIMEOUT — тишина (по умолчанию 12 с).
ATTENTION_TIMEOUT_MUSIC — при музыке (по умолчанию 5 с).
Пока сессия жива, имя повторять не нужно.

Пауза «думаю»: «мм», «эм», «ну», «угу», «так-так», «секунду», «дай подумать» —
молчит, сессию не рвёт.

Other-initiated repair (точные): «что», «а», «как», «не понял», «что сказал», «huh».
Есть последняя мысль — повторяет. Иначе «Слушаю.» / «Да?».
«повтори» / «ещё раз» — follow-up навыков, не глобальный повтор.

Возобновление после «замолчи»:
«продолжай» / «договори» / «дальше» / «на чем мы остановились».

Каша STT: до трёх уточнений («Ещё раз?» → «Какую команду?» → «Если что — позови.»).

Голый глагол («включи», «открой», «найди», «скажи», «поставь») → слот
(«Что включить?»), ждут «музыку» → «включи музыку».

Barge-in: имя во время речи; «стоп» / «замолчи» / «спать» гасят колонку и обрывают Groq.
«замолчи» задачу навыка не отменяет.


3. Стоп, сон, прерывание
------------------------
- «стоп» — речь, Audacious/Glava, сессия в idle, громкость назад.
  В игре «Больше — Меньше» только выход из партии, медиа не трогает.
- «спать» / «отбой» / «все хватит» — idle, медиа не трогает.
- «замолчи» / «подожди» / «хватит говорить» — только речь, сессия слушает дальше.
- «тишина» — стоп музыки в Audacious, сессию не гасит.

10. Биржа (StocksSkill — skills/stocks/)
---------------------------------------
Тумблер «Биржа и портфель»; под ним «Сделки голосом» (по умолчанию выкл)
и «Автоторговля».
`.env`: TINKOFF_TOKEN, TINKOFF_ACCOUNT_ID, TINKOFF_WATCHLIST, TINKOFF_SANDBOX,
TINKOFF_VOICE_TRADE, TINKOFF_AUTO_TRADE.
Без токена — ISS Мосбиржи и quiet_book.json (только чтение).
Сделки — только при включённом тумблере/VOICE_TRADE. Без числа — 1 лот;
«все / целиком» — максимум.
«Что такое акции» → Википедия, не сводка.
Автостол ~45 мин — тумблер или AUTO_TRADE; пустой флаг без JSON — только sandbox.

- «как там портфель» / «что с акциями» / «покажи котировки» / «сводка по счёту»
- «сколько стоит сбер» / «какая цена газпрома»
- «в плюсе портфель» / «какая прибыль по акциям»
- «купи сбер» / «купи три лота сбер» / «продай газпром» / «вложи всё в тмос»
- «поторгуй» / «поработай счётом» / «сыграй на бирже»
  (полный ребаланс при включённых сделках голосом)
- «посоветуй» / «пришли рекомендацию» / «разбери сигналы» — без заявок, в Telegram
- «дневник» / «журнал сделок» — последние сделки в Telegram
Follow-up ~90 с: «подробнее», «ещё», «первая», имя бумаги.


11. Крипта (CryptoSkill — skills/crypto/, спот Bybit)
----------------------------------------------------
Свои тумблеры «Сделки голосом» и «Автоторговля» (не общие с акциями).
Курс без ключа. Счёт/заявки: BYBIT_API_KEY, BYBIT_API_SECRET.
Тестнет: BYBIT_TESTNET=true. Watchlist: CRYPTO_WATCHLIST.
Без суммы — минимум биржи (~5 USDT); «на 20 долларов» — сумма; «все» — максимум.
Только спот. «Что такое биткоин» → Википедия.
Пустой CRYPTO_AUTO_TRADE — авто только на тестнете.
Автостол: раз в ~6 ч полный скор (whitelist BTC/ETH/SOL +watch/позиции), без Groq;
дозор ~12 мин к сохранённой цели: трейл (arm +5%, откат 6% ядро / 8% альты),
TP при пампе ≥12%, риск-офф → кэш,
добор только ядра на просадке ≤−5% (половина дыры), ≤2 сделки дозора/час;
риск-офф по слабому BTC → кэш; bull (BTC 7д ≥ +5%) → кэш ≥8%, иначе ≥25%;
коридор ~4% ядро / ~8% альты; дневной памп ≥ +18% при избытке → фиксация на полном столе;
ядро допускает откат 7д до −8%; без bought.json баланс не зачисляет в стол;
анти-чёрн 12 ч.
«посоветуй» — по-прежнему Groq, заявок не ставит.
Вечером (после 21:00 МСК) при включённом авто — дневной отчёт в Telegram.
Conky: день / с покупки у биржи (₽) и крипты ($); у крипты ещё · кулдаун топ-3.

- «сколько стоит биткоин» / «курс эфира» / «как там солана»
- «что с криптой» / «покажи крипту»
- «купи биткоин» / «купи эфир на 20 долларов» / «продай солану»
- «поторгуй криптой» — тот же скор-стол, что авто
- «посоветуй по крипте» / «какие монеты» — без заявок
- «дневник крипты»

26. Диалог Groq (AIChatSkill)
-----------------------------
Всё, что не забрали узкие навыки: «привет», «как дела», рассуждения.
Короткий ответ голосом, стрим по предложениям.

- «забудь все» / «очисти память»
- «забудь всё обо мне» / «очисти профиль»
- «запомни, что …» / «меня зовут …»
- «что ты обо мне знаешь» / «мой профиль»
- «забудь, что …»

Модель по умолчанию openai/gpt-oss-20b; сильная 120B — из настроек, когда Cursor закрыт.
